# BioGames Architecture Reference

This document describes the as-built architecture of **BioGames**. Read this before adding or modifying games, shared components, or datasets.

---


## 2. Core Conventions

1. **Server/Client Boundary:** Keep files under `app/**` as thin server components that export `metadata` and render a single view or game root. Mark `"use client"` at the lowest sensible level (e.g., `games/<slug>/<Game>Game.tsx` and interactive UI primitives), never on layouts or route pages.
2. **Pure Logic Rule:** Files in `games/<slug>/logic/**` and `lib/**` (outside `lib/hooks/**`) must be pure TypeScript:
   - No React or DOM imports.
   - No `Math.random()` anywhere outside `lib/rng.ts` — accept an `Rng` parameter.
   - No `Date.now()` inside game logic/reducers — pass `now: number` via action payloads.
3. **Shared UI Purity:** Components in `components/ui/**` and `components/game/**` must never contain game-specific rules, copy, or hardcoded options. Pass game-specific controls via slots (`options`, `extraActions`, `children`).
4. **Asset Paths:** Every asset path in code and data must be an absolute path starting with `/` (e.g. `/assets/webp/games/taxo/...`). Organism WebPs are pre-optimized in the Python pipeline (max 1024px, quality 75) and rendered with plain `<img>` to avoid exhausting Vercel's Image Optimization quota.
5. **Naming & Colocation:** Colocate unit tests as `*.test.ts` next to the module they test. Use `@/` imports rooted at the repository root.
6. **Tone & Copy Preservation:** Preserve the author's humor, memes, emojis, and Spanish phrases verbatim when touching existing game copy.
7. **Commits:** Use conventional commit prefixes (`feat:`, `fix:`, `refactor:`, `perf:`, `chore:`, `docs:`) and ensure `npm run check` and `npm run build` pass before committing.

## 3. Platform & Shared API Reference

### `lib/cn.ts`
- `cn(...inputs: Array<string | false | null | undefined>): string` — Joins truthy class names with a space.

### `lib/site.ts`
- `SITE_CONFIG` — Read-only site metadata constant (`name`, `tagline`, `url`, `gaId`, `contactEmail`, `social`, `creator`, `inspiration`).

### `lib/rng.ts`
- `type Rng = () => number` — Uniform PRNG function returning values in `[0, 1)`.
- `hashString(input: string): number` — Stable 32-bit unsigned FNV-1a string hash.
- `createRng(seed: number | string): Rng` — Deterministic Mulberry32 generator seeded by number or string.
- `randomSeed(): number` — Non-deterministic 32-bit unsigned seed from `crypto.getRandomValues` (with fallback).
- `randomInt(min: number, maxInclusive: number, rng: Rng): number` — Uniform integer in `[min, maxInclusive]`.
- `pick<T>(items: readonly T[], rng: Rng): T` — Picks one random item; throws `RangeError` if `items` is empty.
- `shuffle<T>(items: readonly T[], rng: Rng): T[]` — Non-mutating Fisher–Yates shuffle returning a new array.
- `sample<T>(items: readonly T[], n: number, rng: Rng): T[]` — Samples `n` unique items without replacement; throws `RangeError` if `n < 0 || n > items.length`.

### `lib/daily.ts`
- `getDayKey(date?: Date): string` — Formats a date as `"YYYY-MM-DD"` in the player's local timezone.
- `dayNumber(dayKey: string, epochKey?: string): number` — Whole days between `epochKey` (default `"2026-01-01"`) and `dayKey`, DST-safe via `Date.UTC`.
- `msUntilNextDay(now?: Date): number` — Milliseconds remaining until the next local midnight (`00:00:00.000`).
- `dailySeed(gameSlug: string, dayKey: string): number` — Deterministic 32-bit daily seed (`hashString("${gameSlug}:${dayKey}")`).

### `lib/storage.ts`
- `storageKey(gameSlug: string, key: string): string` — Returns `"biogames:<gameSlug>:<key>"`.
- `isStorageAvailable(): boolean` — Safely checks whether `window.localStorage` can be written to.
- `readJSON<T>(key: string, fallback: T, isValid?: (v: unknown) => v is T): T` — SSR-safe JSON reader; returns `fallback` on missing key, parse failure, thrown error, or failed `isValid` guard.
- `writeJSON(key: string, value: unknown): boolean` — SSR-safe JSON writer; returns `false` on error/quota failure.
- `removeItem(key: string): void` — SSR-safe `localStorage.removeItem` wrapper.

### `lib/stats.ts`
- `interface GameStats` — `{ version: 1; played: number; wins: number; currentStreak: number; maxStreak: number; histogram: Record<string, number>; lastRecordedDayKey: string | null }`.
- `emptyStats(): GameStats` — Creates a fresh zeroed `GameStats` object.
- `applyResult(stats: GameStats, result: { dayKey: string; won: boolean; bucket: string }): GameStats` — Pure stats transition (idempotent per `dayKey`).
- `loadStats(gameSlug: string): GameStats` — Reads validated stats from `biogames:<gameSlug>:stats`.
- `saveStats(gameSlug: string, stats: GameStats): void` — Persists stats to `biogames:<gameSlug>:stats`.

### `lib/hooks/*`
- `useCountdown(deadline: number | null, onExpire?: () => void): number | null` — Deadline-based (epoch ms) countdown recomputed every 250ms; calls `onExpire` once when reaching `0`.
- `useWindowKeydown(handler: (e: KeyboardEvent) => void, enabled?: boolean): void` — Window `keydown` listener that ignores events from `<input>`, `<textarea>`, `<select>`, and `contentEditable` elements.
- `useHasMounted(): boolean` — Hydration-safe hook (`false` on server/initial render, `true` on client after hydration) via `useSyncExternalStore`.

### `data/taxonomy.ts`
- `type TaxonRank = "domain" | "kingdom" | "phylum" | "class" | "order"`
- `type TaxonId = string`
- `interface Taxon` — `{ id: TaxonId; label: string; rank: TaxonRank; parent: TaxonId | null; emoji: string; description: string }`.
- `TAXONOMY: readonly Taxon[]` — All 50 taxonomic categories in the dataset.
- `getTaxon(id: TaxonId): Taxon` — Looks up a taxon by ID (case-insensitive); throws on unknown ID.

### `data/organisms.ts`
- `interface Organism` — `{ id: string; name: string; path: TaxonId[]; image: string }`.
- `ORGANISMS: readonly Organism[]` — All 546 organisms imported statically from `data/organisms.json`.
- `getOrganism(id: string): Organism` — Looks up an organism by ID; throws on unknown ID.
- `organismsInTaxon(taxonId: TaxonId): Organism[]` — Returns all organisms whose taxonomic `path` contains `taxonId`.

### `games/registry.ts`
- `type GameStatus = "live" | "coming-soon"`
- `interface GameMeta` — `{ slug: string; title: string; brand: [accent: string, rest: string]; description: string; status: GameStatus; isNew?: boolean; cover?: { card: string; menu: string }; daily?: boolean }`.
- `GAMES: readonly GameMeta[]` — Ordered list of all games shown on the home page.
- `getGame(slug: string): GameMeta` — Returns the `GameMeta` for `slug`; throws on unknown slug.
- `gameMetadata(slug: string): Metadata` — Builds Next.js route `Metadata` (`title`, `description`, `openGraph`) for `app/<slug>/page.tsx`.

### `components/ui/*`
- `Button` (`components/ui/Button.tsx`) — Styled `<button>` with `variant?: "primary" | "secondary" | "danger" | "warning" | "info" | "teal" | "ghost"` and `size?: "sm" | "md" | "lg"`.
- `Modal` (`components/ui/Modal.tsx`) — Viewport-centered `fixed` dialog (`role="dialog"`, `aria-modal="true"`) with Escape/backdrop dismissal and automatic focus management.
- `ConfirmDialog` (`components/ui/ConfirmDialog.tsx`) — Confirmation modal (`message`, `confirmLabel`, `cancelLabel`, `tone?: "danger" | "default"`, `onConfirm`, `onCancel`) without built-in navigation.
- `SegmentedControl<T>` (`components/ui/SegmentedControl.tsx`) — Generic single-select button group (`label`, `options`, `value`, `onChange`) supporting per-option `disabled` and `disabledReason`.
- `Spinner` (`components/ui/Spinner.tsx`) — Accessible loading spinner (`role="status"`).
- `BrandTitle` (`components/ui/BrandTitle.tsx`) — Renders `[accent, rest]` with the green brand gradient on `accent`.

### `components/game/*`
- `GameMenu` (`components/game/GameMenu.tsx`) — Standard pre-game menu shell (`brand`, `coverSrc`, `description`, `options`, `extraActions`, `startLabel`, `onStart`).
- `GameOverModal` (`components/game/GameOverModal.tsx`) — Standard end-of-game modal (`won`, `title?`, `children`, `actions?`, `onClose`) with a close button to inspect the final board and a default "Go back to home" action.
- `GiveUpButton` (`components/game/GiveUpButton.tsx`) — Accessible 🏳️ button (`onClick`, `disabled`, `aria-label="Give up"`).
- `TimerDisplay` (`components/game/TimerDisplay.tsx`) — Responsive countdown label (`secondsLeft: number | null`).

## 4. How to Add a New Game

1. **Registry:** Update the game's entry in `games/registry.ts` (or add a new `GameMeta` entry) with `slug`, `title`, `brand`, `description`, and `cover: { card, menu }`.
2. **Route:** Create `app/<slug>/page.tsx` exporting `export const metadata = gameMetadata("<slug>");` and rendering `<MyGame />`.
3. **Game Module:** Create `games/<slug>/`:
   - `config.ts` — Tunable constants and game rules configuration.
   - `types.ts` — Game-local state and action types.
   - `logic/` — Pure functions + `useReducer` reducer (`*.ts`) and unit tests (`*.test.ts`).
   - `components/` — Game-specific subcomponents.
   - `<GameName>Game.tsx` — `"use client"` root component managing the `"menu" | "playing" | "over"` phase machine (`<GameMenu />` → game board + `<GiveUpButton />` + `<ConfirmDialog />` → frozen board + `<GameOverModal />`).
4. **Cover Art:** Place card (`1:1`) and menu cover images under `public/assets/img/covers/home/` and `public/assets/img/covers/menu/`.
5. **Tests:** Add unit tests for all pure logic and reducer transitions (`npm test`).
6. **Launch:** Set `status: "live"` (and optionally `isNew: true`, `daily: true`) in `games/registry.ts`, then run `npm run check && npm run build`.

## 5. Daily & Persistence Conventions

- **Storage Keys:** Always construct keys with `storageKey(gameSlug, key)` → `"biogames:<slug>:<key>"`.
- **Local Midnight Reset:** Daily challenges use the player's local timezone (`getDayKey()`, `msUntilNextDay()`), resetting at local `00:00`, and derive seeds via `dailySeed(gameSlug, dayKey)`.
- **Streak & Stats Rule:** Handled by `applyResult(stats, { dayKey, won, bucket })`:
  - Winning increments `currentStreak` by 1 and updates `maxStreak`.
  - Losing resets `currentStreak` to 0.
  - Skipping calendar days without playing leaves `currentStreak` unchanged.
  - Recording a result for the same `dayKey` is idempotent.
- **Hydration Safety:** Any client UI that branches on `localStorage` data must gate rendering with `useHasMounted()` to avoid SSR/client hydration mismatches.

## 6. Data Pipeline: Adding or Updating an Organism

1. Drop the source PNG into its leaf taxonomy folder under `raw-assets/taxo/<domain>/<...>/<genus_species>.png`.
2. If the filename stem needs a custom display name (beyond automatic `Genus species` / `Genus spp.` formatting), add an entry to `scripts/data/name_overrides.json`.
3. Run the dataset builder:
   ```bash
   python scripts/build_taxo_dataset.py
   ```
4. Run `npm test` to execute `data/data.test.ts` (verifies all image files exist under `public/`, paths match known taxa in `data/taxonomy.ts`, IDs are unique, and category counts meet minimums).
5. Commit the generated WebP under `public/assets/webp/games/taxo/` and `data/organisms.json`.

## 7. Known Limitations & Deferred Decisions

- **Raw PNG Storage (`E1`):** `raw-assets/taxo/` (1.7 GB of source PNGs) was moved out of `public/` via `git mv` so it is no longer deployed as static public assets, without rewriting git history. Deciding whether to move `raw-assets/` to Git LFS or external storage is left to the repo owner.
- **Placeholder Social URLs (`B4`):** `SITE_CONFIG.social` retains the original placeholder homepage URLs (`instagram.com`, `x.com`, `discord.com`) until real account handles are provided.
- **Third-Party Win Link (`D14`):** The Taxo Bingo win message retains the original link to `https://iamawesome.com` per the behavior contract.
- **Bio Wordle Word List (`E4`):** `public/assets/data/bio_words.txt` is left untouched for curation during the `tasks/bio-wordle.md` implementation.
